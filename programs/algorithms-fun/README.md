# Algorithms Fun

Build one project all the way through. Then start the next one in its own workspace. Each path has ten milestones, a first run you can finish quickly, and a capstone.

| Order | Path | First run | Payoff |
| --- | --- | --- | --- |
| 1 | [Groovebox](curriculum/paths/Groovebox.pdf) | Look up two hits in an eight-step beat. | Play an arrangement with a fill you want to keep. |
| 2 | [Train Dispatcher](curriculum/paths/TrainDispatcher.pdf) | Fix a tiny departure board. | Compare two policies when a track closes. |
| 3 | [Visuals Engine](curriculum/paths/VisualsEngine.pdf) | Put a pulse and flash on the correct frame. | Render a short clip for one of your mixes. |
| 4 | [Festival Control](curriculum/paths/FestivalControl.pdf) | Find the scan that started a gate incident. | Reconstruct the peak and defend the response. |
| 5 | [Datacenter Simulator](curriculum/paths/DatacenterSimulator.pdf) | Find an event in a worker trace. | Replay a failure and explain missed deadlines. |

Open the Groovebox guide and go to The beat that arrived backward. First make the two lookups in [01a.in](fixtures/groovebox/01a.in) match [01a.out](fixtures/groovebox/01a.out). Leave sorting for the next block.

Each path PDF gives commands, worked input/output, build steps, edge cases, and a stopping point. The [fixture files](fixtures/) let you run the examples directly. Write the project and its tests in your own workspace. The cases are public checkpoints for learning and debugging.

The [course and tutor guide](curriculum/Algorithms_Fun_Course.pdf) describes study blocks, fresh checks, and the technical map. The [LaTeX source](curriculum/Algorithms_Fun_Course.tex) and the [path sources](curriculum/paths/) use the same build as the other programs.

From this folder, read the program policy and any saved progress.

```sh
bash ../../course context
```
