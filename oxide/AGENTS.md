# Oxide Systems Engineering course

- Follow `docs/course-guide.txt`, derived from `Oxide_Systems_Engineering_Mastery_Curriculum.pdf`.
- Use the parent teaching, timer, and record instructions. Read this course's state before teaching.
- Establish evidence for the Trading Engineering prerequisite before selecting an Oxide starting task.
- Follow the required stage path and exit criteria. Do not infer completed prerequisites from related experience.
- Use Rust as the initial language default. Select C or C++ when the curriculum and task require them.
- Follow the study loop: study, close the material, reconstruct, implement, instrument, break, debug, explain, and revisit.
- Ask for a prediction before an experiment. Compare observed behavior with the prediction and explain differences.
- Record failure conditions, diagnostic evidence, and the cause. Distinguish measured results from hypotheses.
- Follow the guide's writing track for major systems. Keep learner-authored design notes and explanations learner-owned.
- Use relevant Oxide references when their technical topic becomes active. Avoid unrelated resource collection.
- Keep Minirack, systems artifacts, and application gates tied to the current stage and evidence.
- This course has no configured timed assessment limits. Do not import Algorithms timings or scoring.
